# Systemd

systemd je sistemski servis menadzer u Linux operativnim sistemima.

Provera statusa servisa:

systemctl status naziv_servisa

Pokretanje servisa:

systemctl start naziv_servisa

Zaustavljanje servisa:

systemctl stop naziv_servisa

Restart servisa:

systemctl restart naziv_servisa

Automatsko pokretanje pri podizanju sistema:

systemctl enable naziv_servisa

Pregled servisa:

systemctl list-units --type=service
